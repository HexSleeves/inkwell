# plainpaper

A minimal serif theme for Inkwell's public pages. Run it with:

```bash
INKWELL_THEME_DIR=examples/themes/plainpaper cargo run
```

It overrides every slot, which makes it a useful starting point: delete any file
to fall back to Inkwell's built-in markup for that slot. See `docs/THEMING.md`
for the slot list and the variables each one receives.
